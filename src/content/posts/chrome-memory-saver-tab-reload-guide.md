검색하던 탭으로 돌아갔는데 페이지가 처음부터 다시 뜨거나, 크롬을 오래 켜 놓은 뒤 노트북이 느려진다면 먼저 증상을 나눠 봐야 합니다. 탭을 다시 읽는 동작과 모든 창이 멈칫하는 현상은 원인이 같다고 단정할 수 없습니다.

메모리 절약 모드는 쓰지 않는 탭이 차지하는 메모리를 줄이는 기능입니다. 돌아간 탭에서 다시 로드가 일어나는 것은 이 기능의 정상 동작일 수 있습니다. 반면 현재 보고 있는 페이지까지 느리다면 확장 프로그램, 다른 실행 중인 앱, 특정 사이트의 작업도 따로 확인해야 합니다. [Google의 성능 안내](https://support.google.com/chrome/answer/12929150?hl=ko)

이 글은 컴퓨터용 크롬을 기준으로 합니다. 휴대전화의 메뉴를 같은 이름으로 찾으려 하지 마세요. 설정 이름과 배치는 버전·운영체제·관리 정책에 따라 달라질 수 있습니다. 아래 점검 순서는 원인을 좁히기 위한 권장 절차이며, 특정 기기에서 속도나 배터리 시간이 얼마나 개선됐다는 실측 결과는 아닙니다.

## 설정을 바꾸기 전에 현재 문제를 구분하기

문제를 설명할 때는 ‘크롬이 무겁다’보다 ‘무엇을 할 때 어떻게 달라지는가’를 적는 편이 도움이 됩니다. 예를 들어 이미 열어 둔 기사 탭으로 돌아갈 때만 다시 로드되는지, 주소를 입력하는 순간부터 느린지, 다른 프로그램에서도 입력이 늦는지를 구분합니다.

| 보이는 현상 | 먼저 살펴볼 항목 | 점검할 때 남길 기록 |
| --- | --- | --- |
| 한동안 안 본 탭만 다시 로드됨 | 메모리 절약과 사이트 예외 | 어떤 사이트에서 반복되는지 |
| 특정 페이지를 열면 전체가 버벅임 | 해당 탭과 확장 프로그램 | 그 페이지를 닫으면 달라지는지 |
| 충전기를 뺀 뒤 동작이 달라짐 | 에너지 절약과 전원 상태 | 전원 연결 여부가 같은 조건인지 |
| 크롬 밖의 앱도 함께 느림 | 컴퓨터 전체의 실행 상태 | 동시에 켠 다른 앱이 무엇인지 |
| 한 사이트에서만 표시가 이상함 | 그 사이트의 데이터·확장 기능 | 다른 사이트에서도 같은지 |

이 표는 증상별 출발점을 정리한 것입니다. 표에 나온 설정이 곧 원인이라는 뜻은 아닙니다. 한 번에 여러 설정을 바꾸면 어느 변경이 영향을 줬는지 알기 어려우니, 처음 상태를 기록하고 항목별로 확인하세요.

## 메모리 절약 모드는 어디에서 켜나

크롬 오른쪽 위 메뉴에서 **설정 → 성능 → 메모리 절약 모드**를 확인합니다. Google은 비활성화 시점을 보통·균형·최대로 나누어 안내합니다. 보통은 더 오래 기다리고, 최대는 더 빨리 비활성화하며, 균형은 권장 선택입니다. 비활성 탭은 다시 접근할 때 새로고침됩니다. [설정과 동작 확인](https://support.google.com/chrome/answer/12929150?hl=ko)

처음 점검할 때는 현재 선택을 적어 두고 균형을 기준으로 사용해 보세요. 여기서 중요한 것은 메모리 수치를 가장 작게 만드는 일이 아니라, 작업을 이어갈 때 불편하지 않은 상태를 찾는 일입니다. 자료를 읽는 탭과 입력 중인 업무 화면은 사용 방식이 다릅니다.

예를 들어 문서를 비교하며 여러 기사 탭을 두는 사람은 다시 로드되는 일이 큰 문제가 아닐 수 있습니다. 반대로 작성 중인 게시글이나 계속 상태를 지켜보는 화면은 중간 상태가 중요합니다. 같은 컴퓨터에서도 사이트마다 다르게 다루는 이유가 여기에 있습니다.

## 중요한 작업 화면은 사이트 예외로 좁혀서 관리하기

성능 설정의 **다음 사이트를 항상 활성 상태로 유지**에서 필요한 사이트를 추가할 수 있습니다. 현재 열린 사이트를 고르거나 주소를 직접 입력하는 방식입니다. 영상·통화·다운로드·입력 중인 양식 같은 활동은 탭 비활성화에 영향을 줄 수도 있습니다. [예외와 활동 조건](https://support.google.com/chrome/answer/12929150?hl=ko)

예외에는 계속 유지할 이유가 있는 업무 화면만 넣는 편을 권합니다. ‘언젠가 다시 볼 페이지’까지 모두 추가하면 사용하지 않는 탭을 줄이려던 목적과 맞지 않습니다. 처음에는 문제가 반복되는 사이트만 넣고, 다른 사이트까지 꼭 필요한지 나중에 판단하세요.

예외는 저장 기능이 아닙니다. 브라우저를 닫거나 사이트 세션이 끝나는 상황까지 막아 주는 것으로 생각하면 안 됩니다. 작성 중인 내용은 사이트의 저장 상태를 확인하고, 중요하다면 별도 문서에도 옮겨 두세요. 예외 추가 후에는 같은 화면으로 돌아갔을 때 동작이 달라졌는지 확인합니다.

## 메모리 절약과 에너지 절약을 혼동하지 않기

에너지 절약은 배터리 소모를 줄이려는 기능입니다. 전원이 연결된 상태에서는 작동하지 않으며, 배터리가 있는 Windows·Mac·Chromebook에서 지원됩니다. 일부 백그라운드 작업과 게임·영상의 동작에 변화가 생길 수 있습니다. [Google의 에너지 절약 설명](https://support.google.com/chrome/answer/12929150?hl=ko)

배터리를 쓰는 동안만 체감이 달라진다면 메모리 절약을 무조건 끄는 것부터 시작하지 마세요. 전원 연결 여부와 절전 상태를 먼저 확인해야 비교 조건이 맞습니다. 전원이 연결된 날의 결과와 배터리로 사용한 날의 결과를 그대로 비교하면 서로 다른 조건을 같은 문제로 묶을 수 있습니다.

웹페이지 문제와 배터리 관리를 함께 살펴보고 싶다면 [스마트폰 충전 상한을 정하는 기준](/posts/smartphone-battery-80-percent-charging-guide/)도 참고하세요. 기기별 기능은 다르지만, 절약 설정은 자신의 사용 방식과 함께 판단해야 한다는 점은 같습니다.

## 크롬 작업 관리자에서 무거운 작업 찾기

크롬 메뉴의 **도구 더보기 → 작업 관리자**를 열고 메모리 항목으로 정렬해 어떤 작업이 많은 자원을 쓰는지 확인합니다. Windows·Linux에서는 **Shift + Esc**도 사용할 수 있습니다. Google은 필요 없는 작업을 선택해 종료하는 절차와 함께, 저장하지 않은 작업이 사라질 수 있다고 안내합니다. [작업 점검 안내](https://support.google.com/chrome/answer/1385029?hl=en), [단축키 목록](https://support.google.com/chrome/answer/157179?hl=en)

이 화면에서는 숫자가 가장 큰 항목을 곧바로 종료하기보다 이름부터 확인하세요. 지금 편집 중인 문서, 재생 중인 영상, 업무에 필요한 확장 기능일 수도 있습니다. 더 이상 필요 없는 탭은 일반적인 탭 닫기로 먼저 정리하고, 종료가 필요한 경우에만 작업 관리자를 쓰는 순서를 권합니다.

진단할 때는 ‘문제가 있던 사이트를 열어 둔 상태’와 ‘그 사이트를 닫은 상태’를 비교합니다. 다른 앱까지 함께 종료하면 어느 작업의 영향인지 구분하기 어렵습니다. 수치가 일시적으로 높았다는 이유만으로 이상 프로그램이라고 판단하지도 마세요. 이 글은 특정 메모리 사용량을 정상·비정상으로 가르는 고정 기준을 제시하지 않습니다.

## 확장 프로그램은 삭제보다 사용 중지부터

오른쪽 위 메뉴의 **확장 프로그램 → 확장 프로그램 관리**에서 각 항목을 켜거나 끌 수 있습니다. 도구 모음에서 아이콘의 고정을 해제하는 것은 표시를 숨기는 조작입니다. 확장 기능 자체를 사용 중지하는 것과 다릅니다. [확장 프로그램 관리 방법](https://support.google.com/chrome_webstore/answer/2664769)

최근에 설치한 확장 기능이 있다면 이름과 설치 목적을 적어 두고, 필요 없는 항목부터 잠시 끈 뒤 같은 사이트를 확인하세요. 처음부터 전부 제거하면 설정이나 필요한 기능까지 다시 복원해야 할 수 있습니다. 원인이 확실하지 않을 때는 되돌리기 쉬운 변경부터 하는 편이 낫습니다.

확장 기능의 사이트 접근 권한도 항목별로 확인할 수 있습니다. 선택할 때만 허용하거나, 특정 사이트 또는 모든 사이트에서 허용하는 방식이 안내돼 있습니다. 다만 네트워크를 바꾸는 종류의 확장 기능은 일반적인 사이트 접근 설정과 영향 범위가 다를 수 있습니다. [권한 적용 범위](https://support.google.com/chrome_webstore/answer/2664769)

학교나 회사가 관리하는 브라우저에서는 조직이 확장 프로그램을 제한할 수 있습니다. 설정이 잠겨 있다면 우회 설치로 해결하려고 하지 말고 관리자에게 문의하세요. 문제를 설명할 때는 사이트 주소, 증상, 일시 중지한 확장 이름을 함께 전달하면 확인 범위를 줄일 수 있습니다.

## 캐시·쿠키·다운로드 기록은 지우는 대상이 다르다

‘인터넷 사용 기록 삭제’에서 모든 항목을 고르면 느려짐과 관계없는 데이터까지 영향을 받을 수 있습니다. 특히 다운로드 기록을 지워도 다운로드한 파일 자체가 컴퓨터에서 삭제되는 것은 아닙니다. [삭제 항목별 공식 설명](https://support.google.com/chrome/answer/2392709?co=GENIE.Platform%3DDesktop&hl=ko)

| 항목 | 삭제 대상의 성격 | 선택 전에 확인할 점 |
| --- | --- | --- |
| 캐시된 이미지 및 파일 | 다음 방문을 위해 저장한 페이지 자료 | 다시 필요한 자료를 받아야 할 수 있음 |
| 쿠키 및 기타 사이트 데이터 | 쿠키와 사이트가 저장한 데이터 | 사이트 이용 상태에 영향을 줄 수 있음 |
| 다운로드 기록 | 내려받은 파일의 목록 | 실제 파일 정리와 별개임 |
| 사이트 설정 | 사이트에 부여한 권한과 설정 | 카메라·위치 등의 설정도 포함됨 |

캐시를 지운 뒤 처음 여는 화면이 느리다고 해서 곧바로 더 큰 삭제를 반복할 필요는 없습니다. 필요한 페이지 자료를 새로 읽는 상황과, 사용 중인 탭의 메모리를 줄이는 작업은 구분해야 합니다. ‘삭제하면 무조건 빨라진다’는 전제로 시작하지 마세요.

중요한 사이트에서는 어떤 데이터가 필요한지 확인하고 범위를 정하세요. 계정에 저장한 데이터와 기기에 남은 데이터도 같지 않을 수 있습니다. 브라우저 동기화를 사용한다면 삭제가 다른 기기에 어떻게 반영되는지 공식 안내를 읽은 뒤 진행하는 편이 좋습니다.

## 업데이트 확인과 재시작 전에 저장 상태 점검하기

크롬 메뉴에서 **도움말 → Chrome 정보**를 열면 버전과 업데이트 상태를 확인할 수 있습니다. 준비된 업데이트는 다시 시작해 적용합니다. Google은 일반 창과 탭을 다시 열지만 시크릿 창은 다시 열지 않는다고 안내합니다. [업데이트 적용 방법](https://support.google.com/chrome/answer/95414)

열린 탭을 복원하는 것과 페이지 안의 입력 내용을 보존하는 것은 다릅니다. 제출 전 양식, 업로드 중인 파일, 저장 표시가 확인되지 않은 문서는 먼저 처리하세요. 오래 켜 둔 브라우저를 재시작하는 것보다 지금 진행 중인 작업을 잃지 않는 일이 우선입니다.

업데이트가 계속 실패한다면 다시 설치부터 하지 말고 Chrome 정보 화면의 오류 내용을 기록하세요. 운영체제의 지원 상태도 별도 문제입니다. Windows를 계속 쓰는 조건은 [윈도우 보안 업데이트 안내](/posts/windows-10-esu-2027-extension-guide/)에서 확인하되, 운영체제 지원과 브라우저 설정을 같은 문제로 취급하지 마세요.

## 실제 점검은 같은 조건에서 항목별로

다음은 설정을 비교하기 위한 편집부 권장 기록표입니다. Google이 정한 성능 기준이나 특정 기기에서 측정한 결과가 아닙니다. 변화가 있었는지 기억에만 의존하지 않고 적어 두는 용도로 쓰세요.

| 기록할 내용 | 적는 방법 |
| --- | --- |
| 증상이 나는 동작 | 돌아간 탭이 다시 로드됨, 입력이 늦음 등 |
| 전원 상태 | 충전기 연결 또는 배터리 사용 |
| 비교한 사이트 | 같은 주소와 같은 작업으로 확인 |
| 바꾼 설정 | 메모리 모드, 사이트 예외, 확장 사용 여부 |
| 남은 문제 | 일부 개선, 변화 없음, 다른 문제 발생 |

저장할 작업을 먼저 정리한 뒤 업데이트 상태를 확인하고, 필요 없는 탭을 닫아 보세요. 이어 메모리 절약 수준과 중요한 사이트의 예외를 확인합니다. 그래도 문제가 남으면 작업 관리자와 확장 기능을 살펴보는 순서로 진행하면 변경을 추적하기 쉽습니다.

탭이 다시 로드되는 불편과 컴퓨터 전체의 느려짐이 동시에 있다면 둘 다 같은 설정으로 해결하려 하지 마세요. 어느 동작이 달라졌는지 따로 기록해야 다음 점검이 쉬워집니다. 정확한 원인을 확인하지 못했다면 ‘해결됐다’고 결론 내리지 말고, 반복되는 조건을 남겨 두세요.

## 자주 묻는 질문

### 탭을 많이 열어 두면 메모리 절약을 최대로 해야 하나요?

탭 개수만으로 정하지 마세요. 읽기용 자료를 많이 열어 두는 사람과 여러 업무 화면을 번갈아 쓰는 사람은 필요한 상태가 다릅니다. 균형을 기준으로 작업이 끊기는지 확인하고, 계속 유지할 사이트만 예외에 넣는 편을 권합니다. 최대를 선택했다가 탭을 다시 여는 일이 더 불편하다면 원래 수준으로 돌리고 비교하세요. 이 글은 탭 수에 따른 고정 설정이나 정해진 절약률을 제시하지 않습니다.

### 탭을 고정하면 작성 중인 내용이 반드시 보존되나요?

Google은 탭 고정을 비활성화에 영향을 줄 수 있는 활동으로 안내하지만, 이것을 입력 내용의 보존 보증으로 해석하면 안 됩니다. 탭 유지 설정과 문서 저장은 다른 기능입니다. 제출하지 않은 양식은 저장 상태를 확인하고, 잃으면 곤란한 내용은 별도 문서에 복사해 두세요. 사이트가 자동 저장을 지원한다면 저장 완료 표시까지 확인하는 편이 좋습니다.

### 예외에 넣었는데 페이지가 다시 뜨면 설정이 고장 난 건가요?

예외는 메모리 절약의 비활성화를 막으려는 선택입니다. 브라우저 재시작, 사이트 로그인 상태, 사이트 자체의 화면 갱신까지 모두 통제하는 기능이라고 가정하지 마세요. 먼저 어느 때 다시 로드됐는지 구분하고, 입력한 예외 주소와 문제가 난 주소가 맞는지 살펴보세요. 이유가 확인되지 않은 상태에서는 설정 고장이라고 단정할 수 없습니다.

### 확장 프로그램을 끄자 문제가 줄었다면 바로 삭제해도 되나요?

먼저 다른 조건이 같았는지 확인하세요. 동시에 여러 탭을 닫고 브라우저까지 다시 시작했다면 확장 기능만의 영향인지 구분하기 어렵습니다. 필요했던 기능이 무엇인지 적어 두고 사용 중지 상태로 같은 작업을 비교한 뒤, 유지할지 제거할지 판단하는 순서가 좋습니다. 제거 전에 확장 기능에 저장한 설정이나 자료가 있는지도 확인하세요.

### 캐시를 지우면 브라우저 메모리도 계속 줄어드나요?

인터넷 사용 기록에서 캐시된 이미지와 파일을 삭제하는 조작과, 현재 실행 중인 탭을 관리하는 조작은 다릅니다. 캐시 삭제만으로 사용 중인 모든 작업의 메모리 상태가 원하는 수준으로 바뀐다고 보장할 수 없습니다. 탭을 돌아갈 때의 동작이 문제라면 성능 설정을, 특정 사이트의 표시가 문제라면 그 사이트의 데이터와 확장 기능을 나눠 확인하세요.

### 업무용 컴퓨터에서 설정이 바뀌지 않으면 어떻게 하나요?

조직에서 관리하는 브라우저라면 사용자가 바꿀 수 없는 항목이 있을 수 있습니다. 이때 다른 설치 파일이나 확장 기능으로 제한을 우회하는 방법부터 찾지 마세요. 관리자에게 문제가 나는 주소와 증상, 설정 화면에 나타난 안내를 전달하는 편이 좋습니다. 보안 설정을 약하게 만드는 조작을 속도 개선 수단으로 취급해서는 안 됩니다.
