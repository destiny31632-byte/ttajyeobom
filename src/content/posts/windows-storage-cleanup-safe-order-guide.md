C드라이브가 가득 찼다고 해서 이름이 낯선 폴더부터 지우면 안 됩니다. 용량이 큰 파일이 모두 불필요한 것도 아니고, 클라우드 폴더의 파일을 삭제하는 일이 내 컴퓨터의 사본만 없애는 것일 수도 없습니다. 먼저 저장 공간이 어디에 쓰이고 있는지 확인하고, 각 정리 작업이 무엇을 바꾸는지 구분해야 합니다.

이 글은 Windows 저장소 설정을 중심으로 정리합니다. 주된 설명은 Windows 11 화면을 기준으로 하며, Windows 10에서는 메뉴 배치와 사용할 수 있는 정리 항목이 다를 수 있습니다. Microsoft의 공식 설명을 확인해 구성한 점검 순서이며, 사용자의 파일을 직접 분석하거나 실제 확보 용량을 측정한 결과는 아닙니다.

## 시작은 삭제가 아니라 저장소 분석

**설정 → 시스템 → 저장소**를 열어 설치된 앱, 임시 파일, 시스템 및 예약 항목 등 어디에 공간이 쓰이는지 확인합니다. 다른 드라이브는 고급 저장소 설정의 다른 드라이브 사용량에서 따로 살펴볼 수 있습니다. [저장소 설정 안내](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/storage-settings-in-windows)

화면을 보기 전에 ‘사진이 문제일 것 같다’고 정해 두지 마세요. 앱, 영상, 다운로드한 설치 파일, 클라우드의 로컬 사본 중 어느 것이 큰지에 따라 정리 방법이 달라집니다. 먼저 큰 범주를 좁히고, 그 안에서 필요 없는 대상을 찾는 순서가 좋습니다.

기록할 것은 현재 여유 공간과 가장 큰 항목, 실제로 정리한 대상입니다. 정리 전후를 같은 드라이브에서 비교해야 합니다. 외장 저장 장치의 여유 공간을 늘렸다고 해서 Windows가 설치된 C드라이브의 부족 문제가 해결되는 것은 아닙니다.

| 저장소에서 큰 항목 | 우선 확인할 것 | 피해야 할 조작 |
| --- | --- | --- |
| 설치된 앱 | 더 이상 쓰지 않는 프로그램인지 | 프로그램 폴더 안 파일만 임의 삭제 |
| 임시 파일 | 선택된 항목과 설명 | 내용을 안 보고 모든 항목 선택 |
| 문서·사진·영상 | 원본과 백업 위치 | 사본 확인 없이 원본 삭제 |
| 클라우드 동기화 파일 | 로컬 상태와 동기화 완료 여부 | 공간 확보 대신 삭제 선택 |
| 시스템 및 예약 | Windows 관리 영역인지 | 이름이 낯설다는 이유로 폴더 정리 |

표는 정리를 시작할 지점을 정리한 권장 기준입니다. 특정 항목을 무조건 지워도 된다는 목록이 아닙니다. 업무 자료나 제출할 과제가 들어 있다면 공간 확보보다 복사본을 확인하는 일이 먼저입니다.

## 필요한 파일의 복사본을 먼저 확인하기

삭제 후보를 정하기 전에 다시 구하기 어려운 파일을 생각해 보세요. 직접 찍은 사진, 수정한 과제, 계약 관련 자료, 프로그램 작업 파일처럼 같은 내용으로 다시 받기 어려운 자료부터 보존할 위치를 확인합니다. 폴더 이름에 ‘백업’이 붙어 있다는 사실만으로 다른 곳에 정상적인 사본이 있다고 판단하지 마세요.

복사했다면 복사 대상의 위치와 내용을 확인하고 중요한 파일을 실제로 열어 보세요. 이것은 모든 저장 장치의 장애를 막는 보증이 아니라, 원본을 지우기 전에 최소한 다른 위치에 읽을 수 있는 사본이 있는지 확인하는 절차입니다. 확인하지 않은 복사 작업을 완료된 백업처럼 취급하지 않는 것이 핵심입니다.

외장 장치로 옮기거나 새 파일을 다른 드라이브에 저장하는 방법은 Microsoft도 공간 관리 수단으로 안내합니다. 새 콘텐츠의 기본 저장 위치는 **저장소 → 고급 저장소 설정 → 새 콘텐츠가 저장되는 위치**에서 항목별로 바꿀 수 있습니다. [개인 파일과 저장 위치 관리](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)

기본 저장 위치를 바꾸는 설정과 이미 존재하는 파일을 옮기는 작업은 구분하세요. 사진 앱이나 다른 프로그램이 어떤 폴더를 쓰는지도 확인해야 합니다. 이 글은 프로그램별 설정이나 파일을 일괄 이동하는 명령을 제시하지 않습니다.

## 임시 파일과 정리 권장 사항을 항목별로 읽기

Windows 11의 **설정 → 시스템 → 저장소 → 정리 권장 사항**에서는 임시 파일, 큰 파일이나 사용하지 않는 파일, 클라우드에 동기화된 파일, 사용하지 않는 앱 등을 검토할 수 있습니다. 제안된 항목과 예상 확보 공간을 보고 필요한 대상만 선택하세요. [정리 권장 사항 설명](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)

큰 파일이라는 이유만으로 오래된 자료를 먼저 삭제할 필요는 없습니다. 영상 원본처럼 당장은 자주 열지 않아도 나중에 필요한 파일이 있습니다. ‘자주 사용하지 않음’은 Windows가 보여 주는 정리 단서이지, 소유자가 필요 없다고 확인한 결과가 아닙니다.

다운로드 폴더도 별도로 확인하세요. 설치 파일 외에 인터넷에서 받은 증명서, 수업 자료, 압축 파일의 원본이 섞여 있을 수 있습니다. 파일을 열어 내용을 확인하고, 보존할 항목은 용도에 맞는 폴더로 정리한 뒤 불필요한 것만 지우는 순서를 권합니다.

휴지통에는 복구하려던 파일이 남아 있을 수 있습니다. 오래됐다는 이유만으로 비워도 된다고 판단하지 마세요. 여유 공간을 확인하느라 급하더라도 삭제 대상을 검토하는 시간을 생략하면 안 됩니다. 자동으로 삭제할 범위도 아래 저장소 센스 설정에서 따로 확인해야 합니다.

## 이전 Windows 설치는 되돌아갈 계획과 함께 판단하기

이전 Windows 설치 항목에는 업그레이드 전 설치를 보관하는 Windows.old가 포함될 수 있습니다. Microsoft는 이 항목을 삭제하면 그 파일로 이전 Windows 버전에 돌아갈 수 없고, 삭제 자체를 되돌릴 수 없다고 안내합니다. [이전 설치 정리 주의 사항](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)

따라서 ‘이전 설치가 가장 크다’는 이유만으로 먼저 체크하지 마세요. 업그레이드 후 자주 쓰는 프로그램과 주변 장치가 정상인지, 이전 버전으로 되돌아가려던 이유가 남아 있는지부터 확인하는 편이 좋습니다. 단순한 임시 파일 정리와 같은 무게로 판단할 대상이 아닙니다.

삭제하지 않고 남겨 둔다고 영구적인 복구 수단이 확보되는 것도 아닙니다. 이 글은 이전 버전으로 돌아갈 수 있는 기간을 보장하지 않으며, 정리 버튼을 누르기 전에 현재 Windows의 복구 선택과 Microsoft 안내를 확인하도록 권합니다. 지원 상태가 궁금하다면 [Windows 보안 업데이트 조건](/posts/windows-10-esu-2027-extension-guide/)을 별도로 읽어 보세요.

## 저장소 센스는 자동 삭제 범위를 정한 뒤 켜기

저장소 센스는 임시 파일과 휴지통 항목 등을 정리하는 기능입니다. 설정에서 실행 빈도, 휴지통 보존 조건, 다운로드 폴더 정리 조건을 확인하세요. 사용자의 선택이 다른 로그인 사용자의 설정과 동일하다고 가정하면 안 됩니다. 이 기능은 시스템 드라이브를 대상으로 합니다. [저장소 센스 설정](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/manage-drive-space-with-storage-sense)

자동 기능이라고 해서 모든 개인 파일이 무조건 지워지는 것은 아닙니다. 반대로 켜 놓기만 하면 어떤 파일도 건드리지 않는다는 뜻도 아닙니다. 실제 설정에서 관리 대상과 보존 조건을 읽는 것이 필요합니다. 특히 다운로드 폴더를 자료 보관 장소처럼 쓰는 사람은 해당 정리 선택을 더 신중하게 확인하세요.

처음에는 관리할 범위를 좁히고 정리 결과를 확인하는 편을 권합니다. 휴지통에 잠시 넣어 뒀다가 나중에 되살리는 습관이 있다면 자동 정리 조건이 그 습관과 맞는지도 생각해야 합니다. 다른 사람과 함께 쓰는 컴퓨터라면 각 사용자에게 필요한 자료가 무엇인지 함께 확인하세요.

클라우드 파일을 온라인 전용으로 바꾸는 조건도 저장소 센스에 포함될 수 있습니다. 이는 원본 삭제와 다르며, **이 장치에 항상 유지**로 지정한 파일은 관리 대상에서 제외된다고 Microsoft는 설명합니다. [클라우드 콘텐츠 관리 조건](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/manage-drive-space-with-storage-sense)

## OneDrive의 공간 확보와 파일 삭제는 다르다

OneDrive의 주문형 파일은 필요한 자료만 기기에 내려받아 사용할 수 있게 합니다. 온라인 전용 파일을 열면 다운로드되고, 로컬에 있는 파일은 **공간 확보**로 온라인 전용 상태로 바꿀 수 있습니다. 인터넷 없이 필요한 파일은 **이 장치에 항상 유지**로 지정하는 방식입니다. [파일 상태와 주문형 파일 안내](https://support.microsoft.com/en-us/onedrive/save-disk-space-with-onedrive-files-on-demand-for-windows)

| 선택 또는 상태 | 기기의 사본 | 확인해야 할 사용 조건 |
| --- | --- | --- |
| 온라인 전용 | 원본을 모두 내려받지 않은 상태 | 열려면 인터넷 연결이 필요함 |
| 로컬에서 사용 가능 | 내려받은 파일이 있음 | 이후 정리 설정의 영향을 확인 |
| 이 장치에 항상 유지 | 기기에 자료를 유지하도록 지정 | 그만큼 로컬 공간을 사용함 |
| 공간 확보 | 로컬 사본을 온라인 전용으로 전환 | 원본 삭제 버튼과 구별해야 함 |

출장이나 수업 전에 사용할 자료라면 단순히 파일 이름이 보이는지만 확인하지 마세요. 오프라인에서 필요할 자료는 내려받은 상태를 확인하고 실제로 열리는지 점검하는 편이 좋습니다. 온라인 전용 상태의 파일은 인터넷이 없을 때 열 수 없습니다. [온라인 전용 파일의 제한](https://support.microsoft.com/en-us/onedrive/save-disk-space-with-onedrive-files-on-demand-for-windows)

OneDrive 폴더에서 파일을 **삭제**하면 클라우드와 동기화된 파일에도 영향을 줍니다. 내 컴퓨터의 용량만 줄이려는 목적이라면 삭제와 공간 확보를 혼동하지 마세요. 공유된 항목을 지우는 조작은 다른 사용자에게도 영향을 줄 수 있습니다. [OneDrive 삭제 범위](https://support.microsoft.com/en-us/onedrive/delete-files-or-folders-in-onedrive)

공간 확보를 선택하기 전에 해당 파일이 클라우드에서 확인되는지, 동기화가 끝났는지 살펴보세요. 동기화 오류가 보이면 먼저 해결하고 진행하는 편이 안전합니다. 여러 장치에서 보인다는 사실이 각각 독립된 백업을 갖췄다는 뜻은 아닙니다. 같은 동기화 파일을 서로 다른 곳에서 보여 주는 상태일 수 있기 때문입니다.

## 앱과 시스템 영역은 파일 탐색기로 임의 정리하지 않기

저장소에서 설치된 앱이 큰 비중을 차지한다면 프로그램 이름과 실제 사용 여부부터 확인하세요. 프로그램에 속한 작업 파일이나 내려받은 자료가 있는지도 함께 살펴보는 것이 좋습니다. 프로그램 폴더의 파일만 지워서 용량을 줄이는 방식은 이 글의 정리 절차에 포함하지 않습니다.

시스템 및 예약 공간은 Windows가 임시 파일·캐시·업데이트 등의 작업을 위해 관리하는 공간입니다. 저장소 설정에서는 이런 범주를 따로 볼 수 있습니다. 숫자가 크게 보인다는 이유만으로 개인 문서와 같은 방법으로 정리해서는 안 됩니다. [예약 공간의 목적](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/storage-settings-in-windows)

용량만 보고 어디에 쓸 파일인지 모르는 대상을 골랐다면 여기서 멈추세요. 먼저 앱의 공식 관리 방법이나 Windows가 제공하는 정리 항목을 확인해야 합니다. 이름이 낯선 시스템 폴더를 지우는 명령, 레지스트리 변경, 일괄 삭제 프로그램을 첫 조치로 권하지 않는 이유입니다.

## 정리했는데 용량이 다시 줄어들 때 확인할 기록

공간을 확보했는데 얼마 지나지 않아 다시 부족해지면, 같은 삭제를 반복하기 전에 어떤 항목이 커지는지 확인하세요. 저장소 범주와 다운로드·동기화 상태를 기록하면 다음 점검의 출발점을 정하기 쉽습니다. 아래는 결과를 비교하기 위한 편집부 기록표이며, 특정 컴퓨터의 측정값이 아닙니다.

| 기록 항목 | 확인할 내용 |
| --- | --- |
| 정리한 드라이브 | C드라이브인지 다른 드라이브인지 |
| 정리 전후 여유 공간 | 같은 화면에서 비교한 값 |
| 지운 항목 | 임시 파일, 확인한 개인 파일 등 |
| 클라우드 조작 | 삭제인지 공간 확보인지 |
| 다시 늘어난 범주 | 앱, 임시 파일, 문서 등 |

다운로드가 진행 중이었다면 작업이 끝난 뒤 다시 확인하고, 온라인 전용 파일을 여러 개 열었다면 로컬에 자료가 내려왔는지도 살펴보세요. 새로운 자료가 생기는 경로를 알아야 반복해서 지우는 일을 줄일 수 있습니다. 기록 없이 삭제 범위만 넓히면 필요한 파일을 건드릴 위험도 커집니다.

브라우저의 메모리 문제와 저장 장치의 부족은 다른 항목입니다. 열린 탭을 줄였다고 C드라이브의 파일이 정리되는 것은 아닙니다. 브라우저가 느린 문제를 함께 겪는다면 [크롬 메모리 절약과 탭 점검](/posts/chrome-memory-saver-tab-reload-guide/)에서 증상을 나눠 확인하세요.

## 삭제 전 마지막으로 확인할 것

삭제 후보를 읽었는지, 중요한 원본의 복사본을 열어 봤는지, 다운로드·휴지통·이전 설치 항목의 의미를 구분했는지 확인하세요. OneDrive에서는 온라인 전용으로 바꾸는 조작과 실제 삭제를 다시 구분합니다. 정리한 결과는 같은 드라이브에서 확인하고 기록해 두면 됩니다.

목표는 가장 많은 파일을 지우는 것이 아니라 필요한 자료를 보존하면서 Windows가 사용할 공간을 확보하는 일입니다. 어디에 쓰는 파일인지 확인되지 않는다면 그대로 두고 다른 후보를 먼저 검토하세요. 이 글은 모든 컴퓨터에 필요한 여유 공간을 같은 숫자로 정하거나, 정리 후 성능 향상을 보장하지 않습니다.

## 자주 묻는 질문

### 임시 파일이라고 표시되면 전부 선택해도 되나요?

항목 이름과 설명을 읽고 선택해야 합니다. 정리 화면에는 사용자가 보존하려는 다운로드 자료나 이전 설치 관련 항목이 나타날 수 있으므로, 같은 화면에 보인다고 영향이 같은 것은 아닙니다. 무엇을 제거하는지 이해되지 않는 항목은 선택하지 말고 다른 후보부터 확인하세요. 제안된 확보 용량이 크다는 이유만으로 필요한 확인을 생략하지 않는 것이 중요합니다.

### C드라이브 파일을 다른 폴더로 옮기면 여유 공간이 생기나요?

이동한 폴더도 같은 C드라이브에 있다면 저장 위치만 바뀐 것입니다. 공간을 줄이려면 다른 드라이브로 옮기는지, 필요 없는 파일을 실제로 지우는지, 클라우드 파일의 로컬 사본을 줄이는지 목적을 구분해야 합니다. 다른 드라이브로 옮길 때도 먼저 대상에 정상적으로 복사됐는지 확인하세요. 프로그램이 참조하는 파일은 임의로 이동하지 말고 해당 앱의 관리 방법을 확인해야 합니다.

### OneDrive에 파일 이름이 보이면 오프라인에서도 열리나요?

온라인 전용 상태일 수 있으므로 파일 이름만으로 판단하지 마세요. 온라인 전용 파일은 인터넷 연결이 있어야 열 수 있습니다. 이동 중이나 네트워크가 없는 곳에서 필요한 자료는 장치에 유지하도록 지정하고 내려받기가 끝났는지 확인하세요. 실제로 문서를 열어 보는 점검까지 하면 필요한 순간에 다시 다운로드해야 하는 상황을 줄일 수 있습니다.

### 공간 확보를 눌렀는데 다시 용량을 쓰는 이유는 무엇인가요?

온라인 전용 파일을 다시 열면 기기에 내려받아 사용합니다. 따라서 이후에 같은 자료를 열었다면 로컬 저장 공간을 다시 사용할 수 있습니다. 공간 확보가 자료를 영구적으로 작은 파일로 바꾸는 압축 기능이라고 생각하면 안 됩니다. 항상 유지 설정이 필요한 자료인지, 온라인 전용으로 둬도 되는 자료인지 사용 목적에 맞춰 선택하세요.

### 클라우드 파일을 삭제한 뒤 다른 장치에서도 사라졌어요

OneDrive 폴더의 삭제는 로컬 사본만 줄이는 공간 확보와 다릅니다. Microsoft는 파일이 온라인과 다른 장치에서도 삭제될 수 있다고 안내합니다. 삭제 후 복구가 필요한 경우에는 계정 종류와 서비스의 복구 조건을 확인해야 합니다. 복구가 반드시 가능하다고 가정하지 말고, 추가 삭제나 휴지통 정리 전에 해당 서비스의 공식 복구 안내부터 확인하세요.

### 정리해도 업데이트 공간이 부족하면 바로 초기화해야 하나요?

이 글의 파일 정리 절차만으로 모든 부족 상황을 해결할 수 있는 것은 아닙니다. 먼저 어느 드라이브의 어떤 항목이 남아 있는지, Windows가 요구하는 조치가 무엇인지 확인하세요. 중요한 파일의 복사본도 점검해야 합니다. 초기화는 단순한 정리 버튼과 영향 범위가 다르므로 첫 조치로 진행하지 말고, 현재 오류에 맞는 공식 업데이트 안내를 확인하는 편이 좋습니다.

자료는 2026년 10월 10일 Microsoft 공식 문서를 확인했습니다. 조직에서 관리하는 컴퓨터나 공유 폴더는 관리 정책이 추가로 적용될 수 있으므로, 해당 환경의 담당자 안내를 함께 확인하세요.
