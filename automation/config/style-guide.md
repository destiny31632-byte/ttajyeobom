# 따져봄 글쓰기 기준 (사람·AI 공통)

자동 파이프라인의 AI 프롬프트와 직접 작성하는 글 모두 이 기준을 따릅니다.

## 목표
- 그 검색어로 들어온 독자가 다른 페이지를 더 볼 필요가 없을 만큼 쓸모 있는 글.
- 정보 나열이 아니라 독자의 **결정**을 돕는 글: "그래서 내 상황에선 무엇을 고르면 되나"에 답한다.
- 원자료를 다시 말하는 데 그치지 않는다. 다음 중 여러 개를 반드시 더한다:
  여러 자료 교차 확인 · 비교표 · 장단점 · 상황별 선택 · 흔한 실수 · FAQ · 단계별 방법 · 최신 정보와 예전 정보의 차이. 계산은 검증 가능한 원자료와 계산식이 있을 때만 넣는다.

## 구조
1. 도입 2~3문단: 독자가 궁금한 핵심 질문과 결론을 먼저. 바뀐 점이나 의외의 사실이 있으면 앞에 둔다.
2. frontmatter `summary`: 핵심 요약 3~5개 (각 1문장, 숫자 포함 권장).
3. 새 심층 글은 공백 제외 최소5,000자, H2 소제목8개 이상. 분량을 채우려고 같은 설명을 반복하지 않는다. 본문에 H1(#) 금지.
4. 표3개 이상: 기능 비교·상황별 선택·실수와 예외 등 독자 판단에 필요한 내용. 표 열은6개 이하(모바일). 근거가 없으면 계산표를 강제로 만들지 않는다.
5. "상황별 선택" 또는 "이런 경우엔 A" 섹션.
6. "자주 하는 실수" 섹션.
7. H2 `자주 묻는 질문` 아래 H3 질문6개 이상. 본문을 그대로 반복하지 말고 다른 조건과 예외를 설명한다.
8. 마지막: "오늘 할 일" / "체크리스트" 같은 실행 목록.

## 문체
- 합니다체. 한국어 전문 블로그처럼 자연스럽게. 문장 길이를 섞는다.
- 번역투 금지: "~에 있어서", "~를 통해 ~가 가능합니다", "~하는 것이 중요합니다"(반복), "다양한", "효과적으로" 남발.
- 금지 표현: "오늘은 ~에 대해 알아보겠습니다", "알아보겠습니다", "살펴보겠습니다", "결론적으로", "이 글에서는", "도움이 되셨길 바랍니다", "여러분", "포스팅", "마무리하며", "참고하시기 바랍니다".
- 광고 관련 문구 절대 금지: "광고를 눌러", "광고 클릭", "아래 광고" 등.
- 과장 금지: "충격", "역대급", "무조건", "100%" 같은 표현을 쓰지 않는다.
- 단정 대신 기준을 준다: "보통 ~라면 ~가 유리합니다", "~인 경우에는 예외입니다".
- 출처는 문장 안에서 자연스럽게: "한국전력 요금표 기준", "관세청 안내에 따르면".

## 숫자와 사실
- 바뀔 수 있는 숫자(요금·가격·기간·제도)는 기준일을 적는다: "2026년 10월 1일 기준".
- 출처로 확인되지 않는 숫자는 쓰지 않는다. 추정이 필요하면 가정과 계산식을 밝힌다.
- 자료끼리 다르면 한쪽으로 단정하지 말고 차이와 각 기준을 함께 쓴다.
- 오래된 자료를 최신처럼 쓰지 않는다. 시행일·발표일을 확인한다.
- 계산표 아래에 계산식과 가정(사용 시간, 단가, 환율, 반올림)을 적는다.

## 제목·설명
- 제목 25~45자 권장(최대 60자). 구체적 숫자, 독자가 얻는 이익, 핵심 질문, 비교, 최신 변화, 실수 방지 중 1~2개 활용.
- 제목에 쓴 숫자·주장은 본문에서 반드시 확인할 수 있어야 한다.
- 대상 검색어(targetQuery)의 핵심 낱말을 제목과 첫 문단에 넣는다.
- description 80~150자: 무엇을 알 수 있는지 구체적으로. 과장 금지.

## 출처
- 우선순위: 정부·공공기관 > 제조사·서비스 공식 문서 > 원자료(논문·보고서) > 주요 언론 > 전문 매체.
- 최소 4개, 그중 공식(government/official/primary) 2개 이상.
- 블로그·카페·커뮤니티 글은 출처로 쓰지 않는다.
- 문장을 그대로 옮기지 않는다. 사실만 가져와 새로 쓴다(공식 명칭·짧은 인용 제외).

## 이미지
- 직접 만든 표·차트를 우선한다 (`node automation/cli/chart.ts`).
- 외부 이미지는 라이선스(퍼블릭 도메인, CC0, CC BY, CC BY-SA, 공공누리 1유형)가 확인된 것만, 작성자·원본·라이선스를 frontmatter `images`에 기록한다.
- alt 텍스트는 이미지가 전달하는 정보를 문장으로 쓴다.

## 다루지 않는 주제
사건·사고, 정치, 연예인 사생활, 의료 진단·치료, 개별 투자 추천, 도박·성인·불법 행위, 혐오 표현.
