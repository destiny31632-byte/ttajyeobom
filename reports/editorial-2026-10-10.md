탭이 다시 로드되는 문제와 컴퓨터 전체가 느려지는 문제를 구분하는 데서 시작한다. 메모리 절약 수준, 항상 활성 상태로 유지할 사이트, 에너지 절약의 적용 조건, 크롬 작업 관리자, 확장 프로그램 사용 중지, 캐시와 쿠키의 삭제 범위, 업데이트 전 저장 확인을 순서대로 설명했다.

단순히 메뉴 위치만 나열하지 않고, 설정을 바꾸기 전 무엇을 기록할지와 변경 후 어떤 조건을 비교해야 하는지도 적었다. 세 표는 증상별 점검 출발점, 삭제 항목의 영향 범위, 같은 조건으로 비교하기 위한 기록표로 구성했다. 독자가 설정을 여러 개 한꺼번에 바꾸고 원인을 놓치는 일을 줄이도록 작성했다.

메모리 절약의 사이트 예외를 문서 저장 보증처럼 설명하지 않았다. 탭 유지와 입력 내용 보존을 구분했고, 작업 종료나 브라우저 재시작 전 저장을 확인하도록 안내했다. 확장 아이콘의 고정 해제와 확장 기능 사용 중지도 별개로 설명했다. 캐시 삭제로 모든 메모리 문제가 해결된다는 표현이나 특정 속도 개선률은 넣지 않았다.

### 윈도우 C드라이브 용량 부족, 파일을 잃지 않고 정리하는 순서

파일 삭제와 장치에서만 공간을 확보하는 조작을 구분했다. OneDrive에서 온라인 전용으로 바꾸는 동작과 동기화된 파일을 삭제하는 동작의 차이를 따로 설명했고, 오프라인에서 필요한 파일은 상태를 먼저 확인하도록 했다. 이전 Windows 설치를 지웠을 때 되돌리기에 영향을 줄 수 있다는 점도 정리 전에 볼 수 있도록 배치했다.

시스템 폴더나 예약된 파일을 임의로 삭제하는 방법은 권하지 않았다. ‘몇 기가바이트를 반드시 확보한다’는 수치나 기기에서 직접 측정하지 않은 개선 결과도 넣지 않았다. 실제 확보 공간은 독자의 저장 상태에 따라 달라지므로 정리 전후의 같은 항목을 기록하게 했다.

## 자료 확인과 문장 검토

2026년 10월 10일 기준으로 공식 문서 11개를 직접 읽고, 본문에서 설명한 기능과 조건을 원문에 대조했다. 크롬 글은 Google 고객센터, 윈도우 글은 Microsoft 지원 문서를 중심으로 검토했다. 자료의 주소와 확인 날짜는 각 글에 공개했다.

공식 안내에서 확인한 기능 설명과 편집부가 권하는 점검 순서를 구분했다. 기록표나 작업 순서를 제조사가 정한 성능 기준처럼 쓰지 않았다. 컴퓨터마다 다른 메뉴와 지원 조건도 고정된 사실로 단정하지 않았다.

원문 텍스트를 품질 검사에 제공해 문장 겹침도 확인했다. 크롬 글의 가장 긴 연속 일치 구간은 20자였고, 윈도우 글에서는 연속 일치 구간이 검출되지 않았다. 표시된 포함률은 모두 0.0%지만 반올림된 값이므로 완전히 겹침이 없다는 의미로 사용하지 않는다. 전문용어와 메뉴 이름은 정확성을 위해 유지했다.

한국어 문장은 설정 설명에 필요한 내용 위주로 작성했다. 같은 조언을 표현만 바꿔 반복하거나, 길이를 채우기 위해 서론과 결론을 늘리지 않았다. 각 질문에는 본문에서 놓치기 쉬운 예외와 판단 기준을 답으로 붙였다.

## 공개 문구와 검증 장치

요청한 금지 표현을 새 글 본문뿐 아니라 공개 제목·설명·작성자 소개·하단 안내·편집 원칙·면책 문구에서도 점검했다. 작성 과정은 ‘문장 생성 도구’라는 표현으로 사실대로 설명했다. 계산하지 않은 새 글까지 계산 결과가 있는 것처럼 보이지 않도록 공통 작성 안내도 수정했다.

공개 화면의 텍스트와 설명 메타정보를 검사하는 단계를 전체 검증에 추가했다. 완성된 HTML 83개가 통과했고, 임시 검사 파일에 금지 표현을 넣었을 때 실제로 차단되는 것도 확인했다. 검사 범위는 공개 문구다. 내부 작업 기록과 과거 이력 전체를 지웠다는 뜻은 아니다.

전체 검증에서는 테스트 41개, HTML 83개, 검색 대상 글 11편, 사이트맵 주소 25개를 확인했다. 배포 검사 대상 경로는 피드 등을 포함해 85개다. 페이지 검사는 실패 0건·경고 0건이었다. 정적 파일 121개, 약 1.94MiB로 무료 정적 호스팅 파일 제한 안에 있었다. 이 결과만으로 계정의 모든 무료 이용량을 보증하지는 않는다.

오늘 신규 발행 두 편을 마친 뒤 세 번째 신규 발행을 시도하는 검사도 수행했다. 일일 한도에서 차단됐고, 글이 추가되거나 발행 잠금이 남지 않았다. 실제 신규 글을 세 편 발행한 것은 아니다.

## 발행과 운영 상태

본문을 담은 변경 사항은 저장소에 올렸고, 첫 배포 작업과 공개 서버 확인이 모두 통과했다. 공개 서버에서 새 글 두 편과 기존 글 9편, 홈·문의·개인정보 안내·검색·구독 피드·사이트맵을 검사했다. 공통 작성 안내의 후속 수정까지 배포 작업 38014473147에서 성공했고, 최종 배포 변경 84ed4c3의 공개 서버 본문이 같은 환경으로 생성한 검증 파일과 일치했다. 공개 빌드 식별값의 앞부분은 3e1802d2fda6이다. 로컬 기본 환경의 파일과는 주소 설정이 달라 처음 비교가 실패했지만, 실제 공개 주소로 다시 생성해 전체 비교를 통과했다.

브라우저에서 크롬 글의 제목·본문·표·질문·출처·다음 글 링크가 표시되는 것을 확인했다. 이후 연결이 끊겨 검색창에 직접 입력하는 검사와 화면 캡처는 완료하지 못했다. 검색 페이지 응답과 검색용 글 11편의 생성은 확인했지만, 이를 입력 동작 검증으로 대신 보고하지 않는다.

정기 작업은 신규 글을 하루 최대 두 편 작성·검토·발행하도록 유지한다. 새 글은 공백 제외 약 5,000자 이상을 목표로 하되, 내용 없이 분량을 늘리지 않는다. 공식 자료와 본문 사실이 맞지 않거나 검증을 통과하지 못하면 발행을 멈춘다. 오늘은 두 편을 채웠으므로 추가 신규 발행을 하지 않는다.

정기 글 작성에는 컴퓨터와 데스크톱 앱이 실행 중이어야 한다. 이미 발행한 사이트의 공개와 저장소의 배포 작업은 별도로 동작한다. 글 작성까지 서버에서 독립적으로 실행된다고 보고하지 않는다. 유료 문서 생성 서비스나 추가 크레딧 사용은 하지 않았고, 조회된 잔액은 작업 전후 동일했다.

## 아직 확인하지 않은 결과

기기에서 실제 속도와 확보 공간을 측정한 실험도 하지 않았다. 두 글은 공식 자료를 근거로 한 점검 안내이며, 독자의 기기에서 같은 결과가 반드시 나온다는 보증은 제공하지 않는다. 다음 작업에서는 하루 발행 수와 사용량을 확인하고, 중복 주제를 피하면서 새 공식 자료를 검토한다.
